# Documentação

Esta pasta concentra os documentos de planejamento, apoio e entrega do projeto **Seven Days of Fear**.

O objetivo desta pasta é manter organizada a documentação necessária para explicar a proposta do jogo, registrar decisões de desenvolvimento, indicar referências de assets e apoiar a apresentação final da disciplina.

---

## Arquivos

- `proposta.md`: documento com a proposta inicial do jogo, incluindo nome, integrantes, descrição, objetivos, regras, controles, estrutura planejada, recursos, dificuldades esperadas e escopo da entrega final.
- `README.md`: documentação desta pasta e explicação sobre a função dos arquivos.

---

## Sobre o projeto

**Seven Days of Fear** é um jogo narrativo de sobrevivência zumbi desenvolvido em **Python** com **Pygame**.

O jogador controla um sobrevivente durante 7 dias em uma cidade tomada por infectados. A cada cena, o jogador precisa tomar decisões que afetam seus status, recursos, itens, pontuação, progresso e possíveis finais.

## Referências para assets externos

Os assets do projeto ficam organizados principalmente na pasta:

```text
assets/imagens/
```

Caso o grupo utilize imagens, sons, fontes ou qualquer outro recurso externo, as referências devem ser registradas nesta documentação ou em um arquivo separado, como:

```text
docs/referencias_assets.md
```

Modelo recomendado de registro:

```md
# Referências de Assets

| Tipo | Arquivo | Origem | Licença/Observação |
|---|---|---|---|
| Imagem | inicio.png | Produzida pelo grupo / gerada para o projeto | Uso no projeto acadêmico |
| Fonte | exemplo.ttf | Nome do site ou autor | Licença informada pela fonte |
| Som | exemplo.ogg | Nome do site ou autor | Licença informada pela fonte |
```

Se todos os assets forem próprios ou gerados especificamente para o projeto, registre essa informação para deixar claro que não há uso de recursos externos sem referência.
