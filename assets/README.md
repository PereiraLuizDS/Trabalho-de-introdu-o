# Assets

Esta pasta centraliza os recursos visuais e sonoros do jogo **Seven Days of Fear**.

Aqui ficam armazenados os arquivos usados na parte visual e sonora do projeto, como imagens das cenas, fundos, sprites, ícones, músicas, efeitos sonoros e fontes.

## Organização

- `imagens/`: imagens do jogo, como fundos, cenas, personagens, zumbis, ícones e elementos visuais.
- `sons/`: efeitos sonoros, músicas e trilhas usadas durante o jogo.
- `fontes/`: fontes tipográficas customizadas, caso o grupo utilize alguma fonte diferente da padrão.
- `assets/`: pasta auxiliar para recursos adicionais, caso o grupo precise manter compatibilidade com versões anteriores do projeto.
